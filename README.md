# Groep 9 - Casus 2

Streamlit-dashboard: heeft welvaart in het land van herkomst invloed op het aantal streams van een Spotify-artiest?

Live: https://groep-9-casus-2-blxkbdwtsvstwyvhc7a8mj.streamlit.app

## Lokaal draaien

```
git clone https://github.com/JuadElPedroson/Groep-9-casus-2.git
cd Groep-9-casus-2
pip install -r requirements.txt
streamlit run Home.py
```

Nodig: je eigen Kaggle API-token, opgeslagen als `~/.kaggle/access_token` (aan te maken via kaggle.com > Settings > API).
